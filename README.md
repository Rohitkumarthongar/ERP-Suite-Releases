# ERP Suite releases

Windows installers for ERP Suite, the offline small-business ERP.

Download the latest `ERP-Suite-Setup-<version>.exe` from [Releases](../../releases/latest). Run it to install, or run it over an older version to upgrade. Your data is kept.

Installed copies of ERP Suite check this repository for updates automatically when the PC is online. They also have **Settings → Updates** for checking manually, or for installing from a downloaded file on offline PCs.

This repository only holds release files. The source code lives in a separate private repository. Releases are published automatically by its CI when a version tag is pushed.
